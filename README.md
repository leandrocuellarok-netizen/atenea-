# ATENEA — Repositorio de pensamiento

Sitio estático de ATENEA, repositorio de filosofía, cine, cultura y pensamiento crítico.

## Publicación en GitHub Pages

1. Abrir **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama **main** y la carpeta **/(root)**.
4. Guardar. GitHub publicará el sitio en:

   https://leandrocuellarok-netizen.github.io/atenea-/

## Estructura

- `index.html`: portada, buscador, catálogo, ensayo y presentación.
- `assets/css/styles.css`: identidad visual y estilos responsive.
- `assets/js/main.js`: búsqueda, filtros y navegación móvil.
- `assets/img/favicon.svg`: icono del sitio.

## Archivo y derechos

El WordPress original se conserva como archivo de origen: https://atenearepositorio.wordpress.com/

El ensayo de Leandro Cuellar sobre *La naranja mecánica* se incorporó a esta edición digital. La traducción de “La gran mentira”, atribuida a Molly Haskell y vinculada con *From Reverence to Rape* (1974), no se replica íntegramente aquí: se conserva su referencia y el enlace al repositorio original para evitar republicar material protegido sin autorización.

## Mantenimiento

Para incorporar publicaciones nuevas, actualizar las tarjetas del catálogo en `index.html`. Antes de republicar textos de terceros o traducciones, verificar permisos y atribución.
